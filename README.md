# 🏋️‍♂️ BudiFit – Smart Fitness Challenge System

## 📘 Overview

BudiFit is a smart fitness web application developed as part of the Advanced Web Development course.

The system helps users stay active, motivated, and consistent by offering personalized daily and weekly fitness challenges through an AI-powered assistant named Budi.

BudiFit provides a digital solution for users who want to improve their fitness routine, track their progress, receive motivational feedback, and build healthy habits over time.

This project demonstrates the design and development of a modern web application using React, backend business logic, REST API communication, database integration, and external AI/API services.

---

## 🚀 Features

### 👤 User Services

User Registration and Login: Users can create an account, log in, and access their personal fitness profile.

Personal Fitness Profile: Each user can store personal information such as fitness level, goals, completed challenges, and progress history.

AI Fitness Assistant: Budi interacts with the user, asks questions, recommends challenges, and provides motivational feedback.

Daily and Weekly Challenges: The system suggests fitness challenges based on the user’s level and goals.

Progress Tracking: Users can follow their progress, active days, completed challenges, and current streak.

---

### 🏆 Fitness Motivation

Personalized Challenges: Challenges are adapted to the user’s fitness level and progress.

Motivational Feedback: After completing challenges, the system gives positive feedback and suggestions for improvement.

Notifications and Reminders: The system can remind users to complete their daily fitness challenge.

Social Sharing: Users can share achievements with friends or on social platforms.

Data Export: Users can export workout summaries or progress data, for example as a PDF or by email.

---

## 🧩 System Architecture

BudiFit follows a modern client–server web architecture, including:

Frontend (Client) - React-based user interface for registration, profile management, challenge display, bot chat, and progress dashboard.

Backend (Server) - Handles business logic, user requests, challenge management, progress tracking, and communication with external services.

Database - Stores users, fitness profiles, challenges, completed workouts, streaks, and progress history.

External AI API - Used by Budi to generate personalized recommendations, feedback, and smart fitness challenges.
